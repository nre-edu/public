دفتر مختبر التمريض

قالب واحد يصلح لأي تجربة تمريضية: تتنبأ، ثم تجرّب بالمؤشرات، ثم تثبت بالحساب. ترفع الورقة لترى الحل، وتحصل على ختم.

إضافة تجربة جديدة

كل تجربة في هذه الصفحة وصفٌ واحد بالشكل التالي. لإضافة تجربة تكتب: المدخلات، والمعادلة، وسؤال التنبؤ، ومسألة الإثبات، ورسماً للمشهد. ولا يتغير شيء آخر في الصفحة.

  inputs:  [{ id:"sbp", label:"الانقباضي", unit:"mmHg", min:70, max:200, step:1, value:120 }, …],

  predict: { q:"…", options:[…], correct:1, why:"…" },
  check:   { q:"…", answer:63.3, tolerance:0.5, unit:"mmHg", solution:"…" },
  draw:    (ctx, w, h, v, out, t, colors) => { … }
}

تجارب أخرى تصلح لهذا القالب:

  • توازن السوائل (المدخل والمخرج)
  • مؤشر كتلة الجسم
  • مقياس غلاسكو للغيبوبة
  • معدل تدفق الأكسجين وFiO₂
  • جرعات الإنسولين المنزلقة
  • حساب مساحة الحروق (قاعدة التسعات)
للتدريب فقط. الأرقام أمثلة تعليمية وليست مرجعاً دوائياً أو سريرياً.
